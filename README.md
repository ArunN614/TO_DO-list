# ✅ Task Management Website

A responsive and user-friendly Task Management web application built using **HTML**, **CSS**, **JavaScript**, and **Bootstrap**. This project helps users organize daily tasks efficiently with a clean and interactive interface.

## 🚀 Live Demo

🌐 Visit the Website:  
[Task Management Website](https://taskmang.ccbp.tech?utm_source=chatgpt.com)

---

## 📌 Features

- Add new tasks easily
- Mark tasks as completed
- Delete tasks
- Responsive design for mobile and desktop
- Simple and clean user interface
- Interactive task handling using JavaScript
- Bootstrap-based layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 4
